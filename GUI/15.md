# 第 15 步：完成 Security、Privacy 與 Accessibility hardening

## 目標

針對這個單人本機工具的真實trust boundaries做必要保護，不假裝Tauri會sandbox Python，也不膨脹成enterprise security專案。

## Threat model

需要防：

- WebView/XSS取得不必要的system能力。
- Untrusted assistant/Markdown/provider/MCP文字觸發HTML/script或危險URL。
- Frontend繞過Python path/tool/extension policy。
- Secret出現在DTO、log、error或UI。
- Bash visual confirmation與實際command不一致。
- Destructive prune／force quit／extension apply被誤觸。

不宣稱防：

- 已擁有同一OS使用者完整檔案權限的惡意程式。
- Python `read_file`／bash的完整filesystem sandbox（目前不存在）。
- 跨process extension race或managed-skill integrity debt已修復。

Tauri官方trust-boundary說明：[Security](https://v2.tauri.app/security/)。

## Tauri/WebView權限

- 一個local `main` window，不載remote origin。
- Capability只列實際commands與dialog open。
- 不給shell plugin、broad filesystem、HTTP client、updater權限。
- Rust commands仍驗證method與lifecycle；capability不是business validation替代品。
- CSP以`default-src 'self'`為基準，只加入Tauri IPC/dev所需來源。
- Production不啟用devtools（除非debug build）。

Tauri capabilities/permissions依據：

- [Capabilities](https://v2.tauri.app/security/capabilities/)
- [Permissions](https://v2.tauri.app/security/permissions/)
- [Content Security Policy](https://v2.tauri.app/security/csp/)

## Markdown與links

- Raw HTML完全關閉。
- 不使用`dangerouslySetInnerHTML`呈現assistant/tool/provider content。
- URL scheme allowlist；拒絕`javascript:`、`data:`、`file:`等非預期link。
- External link顯示目的host並要求正常user click；若加入opener plugin需另行權限review。
- Code block永不自動執行。
- Tool/MCP text當plain text，不把ANSI或HTML解釋為markup。

## Secret handling

- Python只回`configured: true/false`。
- 不讀回或顯示Conda env secret值。
- 不把key放localStorage、frontend state snapshot、URL、protocol fixture或log。
- Extension env bindings只顯示source variable名稱與required flag。
- Error redaction涵蓋OpenRouter/OpenAlex/GitHub tokens。
- 若未來要GUI管理secrets，必須另設OS keyring/持久契約批准，不沿用此step。

## Filesystem/path boundary

- React/Rust不直接改store/cite/extension state。
- Native dialog path仍由Python `resolve()`、存在/type與domain policy檢查。
- 不自動轉Windows paths。
- 顯示local path時預設可折疊；copy是explicit action。
- `read_file` tool仍可在denylist外讀任意local path，UI Diagnostics要說明它不是workspace sandbox。
- Skill resource路徑限制與PolicyToolNode不能被GUI bypass。

## Bash approval

- 每call exact immutable approval。
- Default deny、timeout deny、shutdown deny。
- Frontend沒有execution API。
- Approval modal顯示完整command/why/cwd/timeout。
- 不提供remember/allow all。

## Destructive confirmations

- Prune：server preview ID + revalidation + actual deleted result。
- Extension MCP：每binding hashapproval。
- Force quit：指出unflushed/partial-write風險。
- Restart：先flush，明示current citation registry/live context會消失。
- 取消/關閉modal永遠是no-op/default deny。

## Privacy-friendly UI

- Tool args/results、full local paths、stderr預設折疊或不傳。
- No remote telemetry。
- Transcript只在WebView memory，不自動另存。
- Browser/WebView storage只放theme/font等非敏感preferences；若不需要則完全不用。
- Citation bibliography與user answer可見，但raw provider payload不顯示。

## Accessibility checklist

- Semantic landmarks：nav/main/status。
- 每個input有label與error association。
- Keyboard可完成chat、mode、search、preview、approval、confirm。
- Visible focus，不以outline:none移除。
- Modal focus trap與return focus。
- 色彩對比達WCAG AA作為實用基線。
- Status同時用文字/icon，不能只用紅綠。
- Reduced-motion preference；不需華麗動畫。
- Progress使用polite live region並節流。
- Markdown heading hierarchy不破壞app heading層級。
- Zoom/200%時主要actions仍可用。

## 驗證

- 檢查generated Tauri capability schema與production CSP。
- XSS fixtures：raw HTML、script、javascript URL、malformed Markdown。
- Secret fixture確定DTO/log/UI都redact。
- Path traversal/Windows path/symlink/domain refusal。
- Approval mismatch/late response。
- Keyboard-only與screen-reader spot check。
- High contrast/zoom/reduced motion manual QA。

## 驗收條件

- WebView compromised時仍沒有任意shell/fs API。
- 不可信文字不能執行script或command。
- Secret只在Python process environment/provider client中使用。
- 每個destructive action有backend-side token/recheck。
- 可用鍵盤完成四個主要user journeys。
