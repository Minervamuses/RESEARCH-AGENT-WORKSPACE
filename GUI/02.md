# 第 02 步：通過 Linux Tauri 環境與依賴批准閘門

## 目標

在任何 scaffold 前，取得必要批准並建立可重現的 Linux/WSLg toolchain。此步包含 system、Rust、npm、Cargo dependencies，不能自動執行。

## 已確認現況（2026-08-21）

- WSLg 已有 `DISPLAY=:0` 與 Wayland runtime。
- Conda `app`：Python 3.13.14、Poetry 2.4.1、Node 24.18.0。
- WSL PATH 沒有 `rustc` 或 `cargo`。
- `build-essential`、`curl`、`wget`、`file` 已安裝。
- 官方 Debian/Ubuntu Tauri dependencies 中，下列尚未安裝：
  - `libwebkit2gtk-4.1-dev`
  - `libxdo-dev`
  - `libssl-dev`
  - `libayatana-appindicator3-dev`
  - `librsvg2-dev`
- Repo 尚無 `package.json`、npm lockfile、`Cargo.toml` 或 frontend test dependencies。

官方先決條件：[Tauri Linux prerequisites](https://v2.tauri.app/start/prerequisites/)。

## 必須先向使用者取得的批准

### A. System/Rust toolchain

批准範圍應逐項列明：

- 使用 `apt` 安裝上述缺少的 Linux development packages。
- 使用官方 `rustup` 安裝 Rust stable，或使用者指定的既有 system policy。
- 預期成本：數百 MB 級磁碟；首次 Cargo compile 可能數分鐘。
- 維護成本：Linux system packages 與 Rust toolchain 成為 GUI 開發 prerequisite。

不得把這些套件塞入 Poetry 或直接 `pip install`。

### B. Node production dependencies

建議的最小集合：

- `react`
- `react-dom`
- `@tauri-apps/api`
- `@tauri-apps/plugin-dialog`
- Markdown renderer（建議 `react-markdown` + `remark-gfm`，raw HTML 關閉）

不建議第一版加入：router、Redux/Zustand、CSS framework、component library、animation library、icon bundle。

### C. Node development dependencies

- `typescript`
- `vite`
- React Vite plugin
- `@tauri-apps/cli`
- `vitest`
- 最小 React test utilities（若第 16 步確認需要）

### D. Rust dependencies

- Tauri 2 core/build crates。
- `serde`、`serde_json`。
- async process/I/O 所需的最小 Tokio features。
- 官方 dialog plugin Rust crate。

若 Rust standard library + Tauri runtime 已能滿足某功能，就不要另加 crate。

## Package manager 決策

- Node 使用 repo 已具備的 npm，不引入 pnpm/yarn/bun。
- 提交 `package-lock.json`，不使用 floating `latest` 作為可重現狀態。
- Rust 提交 `Cargo.lock`。
- 實作當天選定相容的 Tauri 2.x patch versions，讓 JS/Rust major/minor 相容；版本由 lockfiles 固定。
- `app/env/env-app.yml` 已提供合適 Node 範圍；沒有實證需求時不修改它。
- Python `pyproject.toml`／`poetry.lock` 此架構不需新增 dependency。

## 批准後才可執行的環境檢查

```bash
rustc --version
cargo --version
conda run -n app node --version
conda run -n app npm --version
pkg-config --modversion webkit2gtk-4.1
```

檢查工具與 path 必須來自 WSL/Linux；若出現 Windows `.exe`、`C:\...` 或 system Python，立刻停止。

## 建議的 dependency review 表

每個 dependency 在安裝前記錄：

| 欄位 | 問題 |
|---|---|
| Purpose | 哪個第一版 user-visible behavior 必須用它？ |
| Layer | npm production、npm dev、Cargo、system？ |
| Alternatives | 能否用現有 API 或標準庫？ |
| Security | 是否擴大 WebView/system capability？ |
| Runtime cost | 是否啟動額外 service、port、worker？ |
| Lock | 哪個 lockfile 固定版本？ |

## 不做的事

- 不建立第二個 Conda env。
- 不在 `env-app.yml` 加 Rust/GTK pseudo-dependencies。
- 不加入 FastAPI、Uvicorn、WebSocket、PyInstaller。
- 不使用 Tauri shell plugin 讓 React 任意 spawn command。
- 不安裝 updater、database、keyring、single-instance plugin，除非後續有具體需求並另行批准。

## 驗收條件

- 所有 dependency 與 system install 都有使用者明確批准紀錄。
- `rustc/cargo/node/npm/python/poetry` 全部解析到預期 Linux/Conda runtime。
- WSLg 可建立最小 WebKitGTK window。
- 尚未改動 agent/RAG production code。
- 若任何 prerequisite 無法在 WSL 正常使用，停止並重新評估平台，不改走 Windows native 捷徑。
