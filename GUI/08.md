# 第 08 步：建立單一 live session 的 Chat UI

## 目標

提供可靠、簡潔的chat體驗，忠實呈現現有`ChatSession`能力：一個active session、node/tool progress、最終答案一次完成、無token stream與無可靠cancel。

## Frontend state model

使用React `useReducer`或同等內建機制，不加入全域state library。主要state：

- backend/session readiness。
- current session snapshot。
- live transcript items。
- composer draft。
- active request ID與phase。
- tool activity summaries。
- current modal/approval。
- safe error/recovery notice。

Transcript只在目前WebView memory；不用localStorage偽造session persistence。

## Turn state machine

```text
draft → submitting → running → completed
                         └──→ failed
```

- `submitting`後立即建立user bubble，但標示pending。
- Backend接受request後轉running。
- Progress只更新activity區，不建立假assistant文字。
- `turn_completed`才加入final assistant Markdown。
- Request失敗顯示獨立error card；除非Python已finalize/record，不把error字串寫成assistant turn。
- Retry建立新request ID，保留前次failure context在UI，實際送出文字由使用者確認。

## Composer

- 純文字，多行。
- Enter送出、Shift+Enter換行，可在設定中不做複雜customization。
- Blank、只含control characters、超過protocol limit時前後端都拒絕。
- Running時disable送出，但保留draft編輯可選；最簡單可整體disable。
- 不提供attachment、drag/drop、voice。
- 不解析slash commands；GUI controls取代CLI slash UX。輸入`/status`不得偷偷操作session。

## Assistant Markdown

- 使用成熟Markdown renderer，不自行用regex轉HTML。
- raw HTML關閉。
- GFM table/list/code支援。
- Link protocol只允許安全清單（至少`http`/`https`）；外部開啟策略在第15步固定。
- Code blocks可copy，但不提供一鍵execute。
- Citation renderer輸出的bibliography當普通safe Markdown呈現，不在frontend重新判定identity。
- 超長內容使用可讀layout，不以virtualization dependency先行優化。

## Tool activity

每turn一個折疊區：

- `rag_search — running/returned/errored`
- `citation_workflow — returned`
- 只有安全名稱、時間、狀態。
- 不預設顯示tool args/results、provider raw payload、本機path或traceback。
- Bash exact command只在第09步approval modal顯示。

## Status header

- Plan/Normal。
- Thinking Normal/Extended。
- Active skill/task mode。
- Session ID縮短顯示，完整值可copy。
- Backend/MCP degraded badge。
- Turn busy spinner與elapsed time；elapsed不等於timeout承諾。

## Empty/error states

- Backend未ready：導向Diagnostics。
- Session未ready：顯示reason與retry。
- No messages：提供三個不會自動送出的example prompts。
- OpenRouter error：顯示stable error與設定指引，不顯示key。
- Graph recovery：final answer照常顯示，另以non-alarming notice標示best-effort recovery。
- Citation validation errors：顯示answer已由safety gate處理，details折疊。

## Keyboard與scroll

- 新user turn送出後保持composer focus或依accessibility測試調整。
- 使用者停在底部時auto-scroll；已向上閱讀時不要強制拉回。
- 新progress以small「有新活動」indicator提示。
- Escape不取消turn；只關閉非destructive popover。

## Tests

- Reducer依request ID忽略stale events。
- Progress sequence ordering。
- Double-submit被UI與backend共同拒絕。
- Failure不產生fake assistant message。
- Markdown raw HTML與dangerous URL不執行。
- Scroll/focus與keyboard基本行為。
- Backend restart清楚重置session context。

## 驗收條件

- 一個真實normal turn可完成並顯示finalized answer。
- 運行中無第二turn或mode mutation。
- UI沒有「Stop」或逐token動畫造成不存在的能力承諾。
- Transcript不被標為已持久化或可恢復。
- Tool details預設不洩漏args/results。
