# 第 04 步：定義版本化 NDJSON 協定與 DTO

## 目標

在 Python/Rust/React 各自開始寫 integration code 前，先凍結一個小而明確的 internal protocol。它不是 public network API，也不是通用 RPC framework。

## Transport

- Rust 啟動一個長駐 Python child process。
- Rust → Python：child stdin，每行一個 UTF-8 JSON object。
- Python → Rust：child stdout，每行一個 UTF-8 JSON object。
- Python stderr：logs/diagnostics，永遠不可混入 protocol parser。
- 每行設上限（建議 2 MiB）；超過則回 protocol error 或終止損壞連線。
- 寫入必須有單一 writer lock，確保兩個 events 不會交錯成半行 JSON。

## Envelope

Request：

```json
{
  "protocolVersion": 1,
  "messageType": "request",
  "requestId": "client-generated-uuid",
  "method": "session.turn",
  "params": {"text": "..."}
}
```

Progress：

```json
{
  "protocolVersion": 1,
  "messageType": "event",
  "requestId": "client-generated-uuid",
  "sequence": 3,
  "event": "tool.finished",
  "data": {"name": "rag_search", "status": "ok"}
}
```

Success：

```json
{
  "protocolVersion": 1,
  "messageType": "result",
  "requestId": "client-generated-uuid",
  "ok": true,
  "data": {}
}
```

Failure：

```json
{
  "protocolVersion": 1,
  "messageType": "result",
  "requestId": "client-generated-uuid",
  "ok": false,
  "error": {
    "code": "OPENROUTER_NOT_CONFIGURED",
    "message": "OpenRouter 尚未設定。",
    "retryable": false,
    "details": {}
  }
}
```

## DTO 原則

- 不跨邊界傳 LangChain messages、Pydantic internal objects、`Path` objects、`SessionStartup`、`ExtensionPreview` 或完整 `turn_logs`。
- Path 轉成 Linux absolute UTF-8 string；React 只能顯示／回傳 dialog 選中的 path。
- Enum 使用固定字串，unknown value 要 fail closed。
- Timestamp 使用 UTC ISO 8601。
- Tool event 預設只含 name、call id、status、candidate id（若可靠）；不含 args/result。
- `TurnCompleted` 只含 finalized text、validation errors、safe tool summaries、session/turn ids。
- `RuntimeDiagnostics` 對 secret 只含 boolean。
- `ExtensionPreview` 在 Python server memory 保留完整 object；frontend 只拿 opaque preview ID 與 safe display DTO。

## Ordering 與 correlation

- `requestId` 由 frontend 產生，Rust拒絕重複 pending ID。
- 每個 request 的 event `sequence` 從 1 單調遞增。
- result 是該 request 的 terminal message；terminal 後的 event 視為 protocol violation。
- Backend process-level message可沒有 requestId，但必須是明確的 `backend.ready/crashed` 類型。
- 同 session turn仍單一執行；protocol 能 correlation 不代表 domain 支援 parallel turn。

## Busy enforcement

Python service 回 `BUSY_TURN`、`BUSY_KNOWLEDGE_MUTATION`、`BUSY_EXTENSION_OPERATION`，不要把所有 command 默默排無限長 queue。

讀取 command 是否能與 mutation 並行，第一版保守處理：

- session turn單飛。
- 所有 knowledge mutations共用一把 lock。
- extension preview/apply共用一把 lock。
- mode/skill mutation在 turn busy時拒絕。
- shutdown停止接收新 request。

## Contract fixtures

在實作時建立少量 shared JSON fixtures：

- valid handshake/request/event/result/error。
- unsupported version。
- malformed JSON／missing key／unknown method。
- duplicate request id。
- out-of-order or post-terminal event。
- Unicode/Traditional Chinese/path with spaces。

Python、Rust、TypeScript 各自讀同一批 fixture 驗證，不引入 code-generation framework。

## 驗收條件

- 所有第一版畫面操作能映射到一個具名 method。
- 所有 destructive method 有 preview/approval token，而不是只靠前端 modal。
- Secret、tool result、raw provider payload 不在預設 DTO。
- Protocol version mismatch 會在任何 domain work 前 fail fast。
- 此步仍不啟動 Python child、不改 domain code。
