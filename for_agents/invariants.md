## Enforcement gaps

These cross-cutting gaps matter most when changing code; the per-row cells above hold the details.

- **Permission breadth (INV-018, INV-009, INV-024).**
  - Bypass skips prune confirmation, extension binding choices and installer update consent.
  - Ask silently denies oversized or secret-looking requests.
  - `read_file` and RAG reads are never gated, and `read_file` and bash have no project-root containment (ASM-032).
- **Stop recovery (INV-027).** Cleanup failure wedges the service until restart (FAIL-022), and draining has no deadline (ASM-031).
- **Record privacy (INV-028).** Exception texts written to logs may carry arguments or provider bodies. Log rotation runs only at session or generation start.
- **Generated data (INV-029).** Only the ignore rules enforce it. `/app/store/` coverage was restored in `c12470f` after `app/.gitignore` was deleted (FAIL-021).
- **Citation and web search (INV-030).** The boundary is prompt-only by recorded decision; do not add runtime blocking without a new user decision.
- **Other MCP servers (INV-031).** GitHub and drop-in startup is unbounded (BACKLOG-024).
- **Protocol drift (INV-011).**
  - Four hand-maintained copies, with no shared fixtures for `workspace.select` or `submittedContext`.
  - Declared but unproduced vocabulary (BACKLOG-011).
  - Rust trace validation exists only in tests.
- **Cross-process writers (INV-006, INV-016, INV-025).** Conversations, catalog, `RESEARCH.md` and documents rely on fingerprint prechecks without locks (ASM-016, ASM-022).
- **RAG (INV-008, INV-012).** Mtime/size collisions go undetected, and there is no transaction across Chroma, raw JSON and folder metadata.
- **Thinking errors (INV-005).** Extended rewrite and configuration errors become completed answers.
- **Typography (INV-021).** Fixed-px editor and comment text do not follow the bounded scale.
- **Picker trust (INV-015).** Picked documents are only containment-checked by Python after the fact.
