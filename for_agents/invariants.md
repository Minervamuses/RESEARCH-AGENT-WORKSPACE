### INV-023 — Desktop controls and command catalog belong to Python

The session snapshot owns `slashCommands` (at most 512 entries, canonical names at most 64 UTF-8 bytes) and `bashPermissionMode`. Catalog overflow fails explicitly; React never guesses commands from loaded Skill names. Its catalog/ACK guards require current generation and selected session; menu insertion does not execute. Ask/bypass is process-local per-conversation state, resets to ask for new sessions/restart, and cannot change during active work/approval.

Evidence: `app/desktop/protocol/v1/contract.json` session-result/method definitions, `DesktopService._session_snapshot`/`_session_set_bash_permission`, `composerSlashCommands`, `reconcileBashPermissionAck`; source/config and regression definitions, 2026-09-13 at `a88d44d`. Confirmed contract/implementation; no fresh native run.

### INV-024 — Installer authority and cleanup preserve the selected source

Only actual user intent/replies select a ZIP/candidate or authorize replacing changed existing content. Host preview/apply is scoped to that Skill, disables deletion and excludes unrelated Skill/MCP changes. Original ZIP/bundle bytes are verified; installation does not execute third-party code or install dependencies. Cleanup restores only unchanged, unapplied staged source; conflicts preserve user edits and backup, report their location and stop before a new Skill graph. Persisted thinking metadata describes the effective execution mode. Completed exact replay returns before installer cleanup or re-execution.

Evidence: `app/skills/skill-installer/SKILL.md` and root README installer contract; `SkillInstaller`; `ChatSession`; `test_installer_skill_switch_exposes_cleanup_conflict_without_execution` / `test_installer_skill_switch_persists_effective_mode` / duplicate tests. Confirmed contract and inspected checks at `a88d44d`; no new installation/test run.

Completed Citation replay: `DesktopService._session_turn` defers runtime eligibility for a completed-ID candidate, then still routes through shared parsing and `ChatSession.turn_outcome` canonical identity/fingerprint checks under its turn lock. ## Enforcement gaps

- INV-008: an external raw.json rewrite that preserves both nanosecond mtime and byte size is outside the current conflict detector; no such collision was reproduced in this audit.
- INV-012: prune_orphans does not update folder_meta.json; empty/unreadable re-ingest can retain prior chunks; folder_meta.json is rewritten directly; Chroma/raw/meta writes are not one transaction.
- INV-013: activation re-hashes the managed bundle before reading it; a concurrent writer changing files after that check remains outside the accepted precheck guarantee. FAIL-005 is mitigated, not evidence of immutable storage.
- INV-014: missing/tied years now return ambiguity; unique known minimum selection with other undated candidates remains explicitly tested. Sub-year chronology/relation reasoning is unimplemented, not silently inferred.
- INV-015: the enforced topology is source-checkout-only. Wheel/installer asset lookup and standalone bundling are outside the current contract and unverified.
- INV-018: preview/approval state is process-local. The catalog/conversation stores lack cross-process locking; extension apply separately serializes cooperating writers with its state-root flock.
- INV-019: low-level `activate_citation_skill` retains legacy persistent semantics/docstring, while supported CLI/Desktop paths use explicit one-shot `skill_name`. Root README and `app/SKILLS_GUIDE.md` still conflict with the later Citation contract; preserve the contract and identify stale prose (FAIL-014).
- INV-006: fingerprint verification and atomic replacement do not form an interprocess compare-and-swap; concurrent writers to one conversation remain an inferred race (ASM-022).
- INV-004: PolicyToolNode and trace grouping assume non-empty unique tool-call IDs; duplicate-ID rejection is not directly enforced.
- INV-005: raised provider exceptions in some extended-thinking stages can bypass the common finalizer; tests cover malformed outputs more than raised exceptions.
- INV-009: cooperating Linux extension applies now hold a state-root flock through revision read and durable registry publication. This does not serialize installer staging, arbitrary external writers, conversation files or the catalog.
- Direct desktop `knowledge.init_workspace` and `knowledge.ingest_folder` methods remain declared but deliberately fail; only the composer slash-command route supplies the supported folder-maintenance flow.
- Documentation conflicts: root README still advertises `/skill`/`task_modes` and persistent Citation; `app/SKILLS_GUIDE.md` also retains persistent Citation wording. Its Bash summary describes CLI defaults rather than Desktop bypass; academic-paper-writing's prose restriction remains instruction-level (ASM-011).
