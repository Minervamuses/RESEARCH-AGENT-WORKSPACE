01用原生介面選擇資料夾與檔案

使用者意見與要求

每次啟動後看到的專案選擇畫面，需要自己輸入路徑，非常不直觀。希望像附圖二的 Codex Desktop，跳出 Windows 原生選擇介面，直接瀏覽、選取資料夾；開啟檔案進行編輯時也要如此。

已確認 現況與形成原因

專案選擇器是 React 自製對話框，以 Project folder 文字欄位和 Inspect project 按鈕讓使用者手動指定路徑。輸入內容作為 rootPath 傳給 workspace.select，不是由原生選擇器回傳路徑。

chooserOpen 初始值為 true，但畫面須等後端 ready 且診斷資料存在才呈現。因此附圖五的「後端尚未啟動」與附圖一的「要求輸入專案路徑」是啟動流程的不同階段。

02每個反白區域都有獨立留言

使用者意見與要求

附圖三已反白並加入兩個地方，但無法針對每一段分別輸入文字。希望像附圖四：每個反白區域都有編號與自己的文字輸入框；輸入完按 Enter，就收成小型數字標記。

03執行後直接能用，不再多按啟動

使用者意見與要求
