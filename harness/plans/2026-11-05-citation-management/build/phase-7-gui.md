# C7 GUI 引用面板

- **後置條件**：開啟 Markdown 或 LaTeX 文件時，GUI 有一個引用面板，可以看書目與正文引用、跳到位置、增刪條目、選格式、預覽與匯出；編輯器輸入 `[@` 或 `\cite{` 時能自動補全 key。
- **目標**：CG3、CG4、CG5。假設 A4、A5、A10；風險 R6。
- **相依**：C6。

## 設計約束

- React 只收集意圖與顯示有界的資料；所有寫入與驗證由 Python 處理（既有的桌面信任分工）。
- 書目字串與渲染結果都是不可信文字，一律經 `SafeContent` 顯示。
- 面板在文件開啟、手動儲存成功、`document.apply` 成功、按下「重新整理」時呼叫 `bibliography.inspect`；不在每次按鍵時呼叫。
- 介面文字沿用 GUI 現有的語言。

## 步驟

| 步驟 | 工作 | 必要檢查 |
|---|---|---|
| C7-S1 | **檢視**。面板分區：「本文引用」（依首次出現順序；數字制樣式時顯示編號；每筆顯示 key、作者年份標題、引用次數、驗證狀態；展開後列出位置，點擊位置讓 Monaco 捲到並選取該範圍）、「問題」（找不到的 key 附位置、重複 DOI、書目錯誤）、「未引用的條目」。沒有開專案或沒有書目時顯示說明而不是錯誤 | `desktop/tests` 新增測試：inspect 結果到面板狀態的轉換（排序、編號、計數、問題分類）；點擊位置產生正確的編輯器範圍（含 emoji 的 UTF-16 位移）；`npm test`、`npm run build` 通過 |
| C7-S2 | **增刪與補全**。刪除：條目仍被本文引用時先以確認對話框說明次數，並註明「其他文件未檢查」，確認後帶指紋呼叫 `bibliography.remove`，衝突時提示重新整理。新增：輸入 DOI 或 arXiv ID 呼叫 `bibliography.add`，Ask 模式下沿用既有批准 UI；成功後顯示 key，並提供「插入到游標」（只改 Monaco 中的未儲存文字，Markdown 插入 `[@key]`，LaTeX 插入 `\cite{key}`）。補全：註冊 Monaco completion provider，在 `[@`、`; @`、`\cite{`、`,` 之後列出 key 與標題 | 測試：刪除前確認的條件與文字；衝突處理；新增成功/拒絕/失敗三種結果的狀態轉換；插入文字依副檔名不同；補全觸發條件與候選內容；`npm test`、`npm run build` 通過 |
| C7-S3 | **格式、預覽與匯出**。樣式下拉選單（顯示 C4/C5 的樣式清單，選擇後呼叫 `bibliography.set_style`；回合進行中停用並提示）；「預覽」呼叫 `bibliography.render`，列出逐筆引用與參考文獻；匯出按鈕：Markdown 文件有 DOCX、Markdown、BIB，LaTeX 文件只有 BIB；完成後顯示寫出的路徑 | 測試：切換樣式送出正確請求；回合進行中不可切換；預覽結果經 SafeContent 顯示斜體；`.tex` 文件只出現 BIB；`npm test`、`npm run build` 通過；沙箱外 `cargo test --locked` 通過 |

## 失敗與恢復

- 無法在原生視窗中操作，是本計劃已知的限制（R6）：以測試與後端端到端驗收為準，C8 的最終彙報附上手動 GUI 檢查清單。
