## 手動 GUI 驗收清單（交付給使用者，執行者不操作）

準備七類文件（S1 §8.3）：多層章節的 Markdown 論文、多層章節的 LaTeX 論文、中英混合標題、大量章節的長文件、同名章節、沒有標題、正在編輯（語法未完成）。執行者在 `evidence/D8-S3/fixtures/` 提供這些範例檔，使用者複製到自己的專案中開啟。

1. 啟動後左側是對話管理，內容與以前相同；圖示列在最左邊。
2. 開一份 `.md`：側欄自動換成大綱，層級正確；再開一份 `.tex`：換成新文件大綱，沒有前一份殘留。
3. 點圖示切換兩種檢視；點目前圖示收合、再點展開；收合時開檔，圖示切到大綱但側欄維持收合（A4）。展開時兩種檢視都看得到品牌與 Backend 狀態、Start／Restart／Shut down；收合時它們一起隱藏（U6 的預期後果），主區佔滿其餘寬度、沒有空欄。
4. 點各章節：游標到標題行、標題在頂端附近、焦點在編輯器、沒有 `Add comment`；點最後一章（例如 Conclusion）高亮不跳回前一章。
5. 捲動與移動游標時目前章節正確；收合父節點後，目前章節的祖先有標示。
6. 打字新增、刪除、改名、改層級、貼上大段內容，大綱即時更新且收合狀態保留；Ctrl+Z／Ctrl+Shift+Z 後正確；讓 Agent 修改文件後正確；觸發版本衝突並處理後正確。
7. 跳轉、捲動、收合後，Undo 歷史仍在、文件沒有變成未存檔（除非有編輯）、沒有觸發存檔或 Agent 回合。
8. 拖曳兩條邊界：寬度改變、Monaco 跟著重新排版、不會選到文字；雙擊恢復預設；重開 app 寬度保留；鍵盤 Tab 到邊界後左右鍵可調。
9. 把視窗縮到 1000 px 與 740 px：分別只剩側欄邊界與沒有邊界，圖示列在 ≤ 760 px 變成橫列，版面沒有重疊或水平捲軸。先在全螢幕把側欄拉到最寬、文件欄拉到最寬，再把視窗縮到 1060 px 與 900 px：仍沒有水平捲軸，文件與對話欄都看得到；放回全螢幕後恢復剛才拉的寬度。
10. `.tex` 有顏色區分；`\cite{`、`\citep{`、`\textcite{` 補全會出現，按 Esc 後繼續打字補全會再出現；`.md` 的 `[@` 補全照常。
11. 鍵盤：Tab 進入大綱，上下左右、Home／End、Enter 符合 D7；在 Composer 以中文輸入法打字按 Enter 不受影響。
12. 長文件（大量章節）打字不卡頓；引用面板、段落引用、批註、核准對話框照常。
