# 文件大綱側欄與可拖曳欄寬：目標與決策

本檔記錄穩定的目標、範圍與決策。路線與執行契約在 [PLANS.md](PLANS.md)，狀態與證據只記在 [build-log.md](build-log.md)。

## 目的

1. 桌面 GUI 的左側欄可以在「對話管理」與「目前文件的大綱」之間切換。切換方式比照 VS Code：最左邊有一條直立的圖示列。剛開啟系統時顯示對話管理，跟現在一樣。使用者開啟一份文件後，左側欄自動換成這份文件的大綱；再開另一份文件（一次只開一份），自動換成新文件的大綱。
2. 大綱從目前編輯器內容（Markdown 或 LaTeX 原始碼）即時算出，點標題可跳到該處，閱讀或編輯時會標出目前所在章節。
3. 欄與欄之間的直立邊界（側欄｜文件｜對話）可以用滑鼠左右拖曳改寬度，寬度會記住；上下方向的邊界不做。
4. P1：`.tex` 有 LaTeX 語法高亮，大綱可以用鍵盤操作。
5. 修好一個既有缺陷：文件編輯器的引用補全清單目前完全不會出現（U10）。

## 必須保持的不變條件

- **單一使用者、單一專案、單一文件、單一回合**（CLAUDE.md、INV-035）：不為並行使用加任何鎖或全域狀態控制器。
- **原始碼是唯一的事實來源**（S1 §4.2）：大綱是從 `sourceText` 算出的衍生狀態；不寫回文件、不寫進 `RESEARCH.md`（INV-016、FAIL-026）、不另存 JSON、不進 Agent context（INV-026、INV-034）、不用 LLM。
- **編輯器生命週期**：只有換檔（`[rootPath, path]` 改變）才重建 Monaco model；大綱、跳轉、追蹤、拖曳都不能重建編輯器或清掉 Undo 歷史。新增的 listener 在換檔與卸載時釋放。
- **位置換算**：沿用 `app/desktop/src/lib/documentSource.ts` 的 UTF-16 offset 與行列換算，不另建一套。
- **字級與縮放**（INV-021）：`:root` 的 `clamp(...)`、`editorZoom.ts`、`.citation-panel >= 0.9rem` 不動。
- **離線打包**：所有程式與圖示在本地打包，不從 CDN 載入（`DocumentEditor.tsx` 既有註解的做法；S2 brief 把這條標成 INV-029 是誤標，INV-029 實際是「產生的 store、secrets、`.env` 不提交」，同樣要遵守）。
- **LF 換行**（INV-002）。

## 解析規格（G1 的驗收依據，摘自 S1 §3.2–3.4）

**Markdown**

- 辨識 ATX 標題 `#`–`######`（含合法的結尾 `#`）與 Setext 標題（`===` 為一級、`---` 為二級）。
- 標題文字去掉行內格式標記（粗體、斜體、行內程式碼的符號去掉，連結只留顯示文字），保留文字內容。
- 不當成標題：fenced code block、indented code block、HTML 註解、YAML front matter、不合語法的 `#`（例如 `#標題` 沒有空白）、引用區塊與清單項內的標題。
- 允許不連續層級、文件開頭沒有一級標題、同名標題、尚未打完的語法（例如沒有關閉的 ``` 或 `<!--`）。

**LaTeX**

- 指令：`\part`、`\chapter`、`\section`、`\subsection`、`\subsubsection`、`\paragraph`、`\subparagraph`，依彼此的相對層級建立樹（文件可以直接從 `\section` 開始）。
- 支援 `*`、可選參數 `[短標題]`（大綱顯示完整標題）、跨行標題、巢狀大括號、常見行內格式指令（例如 `\textbf{}`、`\emph{}` 取其文字）。
- 不當成章節：`%` 註解中的指令（`\%` 不是註解）、`verbatim`／`verbatim*`／`lstlisting`／`minted`／`comment` 環境、`\verb` 與 `\verb*`、`\newcommand`／`\renewcommand`／`\providecommand`／`\def` 的定義內容。
- 尚未打完的指令（例如 `\section{Intro`）不使整個解析失敗，前面已完成的章節照常可用。

**共同輸出**

- 節點至少有：`id`、`title`、`level`、`lineNumber`、`startOffsetUtf16`（標題起點）、`headingEndOffsetUtf16`、`sectionEndOffsetUtf16`（到下一個同級或更高層級標題之前，或文件結尾）、`children`。
- offset 以原始 `sourceText`（含 BOM、CRLF）的 UTF-16 單位計算。
- **ID**：從根到節點的路徑，每段是 `(level, 正規化標題, 序號)`，序號只計算同一父節點下、層級與標題都相同、排在前面的兄弟。因此在上方新增或刪除無關章節不會改變其他 ID；同名兄弟以序號區分；同名兄弟的插入、刪除或改名可能使其餘同名節點重新編號，子孫的路徑也會跟著改變。跨版本跳轉須依 D5 辨認原節點。
- 兩種格式各自解析，不把一種轉成另一種再解析。
